# مكتبة أبجد — موقع الملازم والاختبارات

موقع يعرض الملازم وأسعارها في بطاقات مع بحث وفلترة، ويتيح لولي الأمر اختيار ما يحتاجه وإرسال الطلب إلى واتساب المكتبة، مع اختبارات تفاعلية مجانية للطلاب. يعمل على GitHub Pages بدون سيرفر أو قاعدة بيانات، ويمكن تثبيته على الموبايل كتطبيق، وله مظهر فاتح وداكن.

## الملفات

| الملف | وظيفته |
|---|---|
| `data/products.json` | بيانات المكتبة (الاسم، واتساب، انستاباي، التوصيل) والملازم والصفوف والمواد |
| `data/quizzes.json` | قائمة الاختبارات وربط كل اختبار بملف HTML |
| `quizzes/` | ملفات الاختبارات (HTML) |
| `index.html` و `css/` و `js/` | شكل الموقع وكوده (لا تحتاج تعديلها عادةً) |
| `manifest.json` و `sw.js` و `icons/` | تثبيت الموقع كتطبيق |

## 1) ضبط بيانات المكتبة

افتح `data/products.json` وعدّل الجزء الأول `library`:

```json
"library": {
  "name": "أبجد",
  "tagline": "اختر ملازمك ونحن نطبعها لك",
  "whatsapp": "201000000000",
  "deliveryFee": 10,
  "currency": "جنيه",
  "instapay": { "address": "abgad@instapay", "accountName": "مكتبة أبجد" }
}
```

- `whatsapp`: الرقم بالصيغة الدولية بدون `+` (مثال لرقم مصري: `201012345678`). ويقبل الموقع أيضًا `01012345678`.
- `deliveryFee`: رسوم التوصيل، تُضاف مرة واحدة على الطلب كله.
- `instapay.address`: عنوان انستاباي الذي يحوّل إليه العميل عند اختيار التوصيل.

**الرقم وعنوان انستاباي الموجودان حاليًا تجريبيان، استبدلهما قبل النشر.**

## 2) إضافة وتعديل الملازم

كل ملزمة سطر في مصفوفة `products`:

```json
{ "id": "p3-math-t1", "name": "ملزمة الرياضيات - الترم الأول", "grade": "p3", "subject": "math", "price": 25 }
```

- `id`: اسم فريد لا يتكرر (حروف إنجليزية وشرطات).
- `grade`: رمز الصف من قائمة `grades` (`p1` إلى `p6` للابتدائي، `m1` إلى `m3` للإعدادي، `s1` إلى `s3` للثانوي).
- `subject`: رمز المادة من قائمة `subjects`. لإضافة مادة جديدة أضف سطرًا في `subjects` ثم استخدم رمزه.
- لإخفاء ملزمة مؤقتًا (نفدت مثلًا) أضف `"available": false` ولا تحذفها.
- انتبه للفواصل بين الأسطر وعدم وجود فاصلة بعد آخر عنصر. لو أخطأت في الملف يستمر الموقع في استخدام آخر نسخة سليمة.

**أيقونة ولون المادة:** كل مادة لها أيقونة ولون جاهزين يظهران على البطاقات. لتغييرهما أضف الحقلين `icon` و `color` للمادة في `subjects`:

```json
{ "id": "math", "name": "الرياضيات", "icon": "📐", "color": "blue" }
```

الألوان المتاحة: `blue` و `coral` و `purple` و `green` و `orange` و `teal` و `pink` و `yellow`.

البيانات الحالية تجريبية، فاستبدلها بملازمك الحقيقية.

## 3) إضافة اختبار تفاعلي

1. ضع ملف الاختبار (HTML) داخل مجلد `quizzes/`.
2. أضف سطرًا في `data/quizzes.json`:

```json
{
  "id": "q-p4-arabic-1",
  "title": "اختبار على الهمزة",
  "description": "اختبر نفسك في كتابة الهمزة",
  "grade": "p4",
  "subject": "arabic",
  "file": "quizzes/p4-arabic-hamza.html",
  "questions": 8,
  "minutes": 5
}
```

- `grade` يمكن أن يكون أكثر من صف: `"grade": ["p4", "p5"]`.
- `questions` و `minutes` اختياريان، ويظهران على البطاقة إن كتبتهما.
- كل الاختبارات مجانية وتظهر بعلامة «مجاني».
- يفتح الاختبار داخل التطبيق وبجواره زر «فتح في صفحة مستقلة».
- **المظهر الداكن:** يرسل التطبيق المظهر الحالي للاختبار في الرابط (`?theme=dark` أو `?theme=light`). إن أردت أن يطابق ملف اختبارك المظهر، اقرأ هذا الباراميتر في ملفك. الاختبارات الجاهزة في المجلد تفعل ذلك، ويمكنك نسخ أحدها كقالب (الأسئلة في مصفوفة `QUESTIONS` أعلى الكود، وتدعم الاختيار من متعدد وصح وغلط).

## 4) البحث والفلترة

- **الملازم والاختبارات:** مربع بحث (يتجاوز اختلاف الهمزات والتاء المربوطة)، وفلتر المادة، وفلتر الصف، وزر «ملازمي / الكل».
- **الملازم:** ترتيب حسب السعر أو الاسم.
- «ملازمي» تعرض ما يطابق صفوف ومواد العميل المحفوظة فقط، و«الكل» تعرض كل المحتوى.

## 5) منطقة العميل (حسابي)

- **طلباتي:** كل طلب أرسله العميل يُحفظ تلقائيًا (رقم الطلب، التاريخ، الملازم، الإجمالي، طريقة الاستلام). ويمكنه إعادة الطلب بضغطة أو حذفه من السجل. عند إعادة الطلب تُحسب الأسعار الحالية، والملزمة التي لم تعد موجودة تُتجاهل.
- **اهتماماتي:** تعديل الاسم والصفوف والمواد.
- **الإعدادات:** المظهر (تلقائي / فاتح / داكن)، وتثبيت التطبيق، وتحديث القائمة.
- سجل الطلبات واهتمامات العميل محفوظان في متصفحه فقط. إذا غيّر الجهاز أو مسح بيانات المتصفح يبدأ من جديد، ولا يظهر السجل للمكتبة.

## 6) الرفع على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub وارفع محتويات هذا المجلد كلها.
2. من المستودع: **Settings** ثم **Pages**.
3. في **Source** اختر **Deploy from a branch**، والفرع `main`، والمجلد `/ (root)` ثم **Save**.
4. بعد دقيقة أو دقيقتين يظهر الرابط: `https://اسم-المستخدم.github.io/اسم-المستودع/`.

كل تعديل على ملفات `data/` تحفظه (Commit) يظهر للعملاء خلال دقائق، بدون أي إجراء من جهتهم. الموقع يعيد فحص الملفات كل دقيقة أثناء فتحه، وعند الرجوع إليه.

## 7) التجربة على جهازك قبل الرفع

لا تفتح `index.html` بالنقر المزدوج، لأن المتصفح يمنع قراءة ملفات JSON بهذه الطريقة. شغّل خادمًا محليًا من داخل المجلد:

```
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## 8) تثبيت التطبيق على الموبايل

بعد أن يختار العميل صفه ومواده ويكتب اسمه تظهر له شاشة التثبيت. وتجده أيضًا في حسابي ثم الإعدادات.

- **أندرويد (Chrome):** زر «تثبيت التطبيق» يثبته مباشرة.
- **آيفون (Safari):** زر المشاركة ثم «إضافة إلى الشاشة الرئيسية» (آبل لا تسمح بزر تثبيت مباشر).
- التثبيت يتطلب رابطًا يبدأ بـ `https`، وهو متوفر تلقائيًا على GitHub Pages.

## كيف يعمل الطلب

1. العميل يختار الملازم من البطاقات، ثم يراجع الطلب ويكتب اسمه.
2. **استلام من المكتبة:** يضغط «إرسال الطلب عبر واتساب» فتفتح رسالة جاهزة بالقائمة والإجمالي.
3. **توصيل:** تُضاف رسوم التوصيل، ويكتب العنوان، ويحوّل المبلغ عبر انستاباي أولًا ويؤكد التحويل، ثم تُرسل الرسالة ويرسل صورة التحويل في المحادثة.

المكتبة تتأكد من التحويل بنفسها قبل التنفيذ، لأن الموقع لا يستطيع التحقق من الدفع. ويُحفظ الطلب في سجل العميل عند فتح واتساب، حتى لو لم يضغط إرسال داخل المحادثة.

## ملاحظات

- الخطوط (Cairo وLalezar) تُحمَّل من Google Fonts. إن لم تتوفر يعرض الموقع خطًا بديلًا.
- إذا عدّلت ملفات الموقع نفسها (وليس `data/` فقط) وأردت أن يصل التحديث لمن ثبّت التطبيق، غيّر رقم النسخة في أول سطر من `sw.js` (`abgad-v2` إلى `abgad-v3` مثلًا).
